# Landing Page — Técnicas Modernas de Investigación Policial

Sitio estático en HTML, CSS y JavaScript puro, listo para GitHub Pages.

## Publicación
1. Subir el contenido completo de esta carpeta a un repositorio.
2. En GitHub: Settings → Pages.
3. Elegir Deploy from a branch, seleccionar `main` y `/ (root)`.
4. Guardar y esperar la publicación.

## Archivos
- `index.html`: estructura y contenido.
- `css/styles.css`: diseño adaptable.
- `js/main.js`: menú móvil y navegación activa.
- `assets/`: gráficos e informe PDF.

El mapa se integra mediante Google My Maps. Para verlo embebido, el mapa debe permitir su visualización por enlace.
